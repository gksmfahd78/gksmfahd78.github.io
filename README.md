- LLM developer tools
- Full-stack web applications
- Unity and C# projects

## Local Development

This site is based on a Jekyll theme and is deployed with GitHub Pages.

```bash
bundle install
bundle exec jekyll serve
```

Then open:

```text
http://localhost:4000
```
